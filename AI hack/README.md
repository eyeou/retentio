# Retentio AI Hack

This folder contains presentation-ready material for the Retentio hackathon MVP: cinematic visuals, product framing, and assets that can be used in slides, demos, pitch decks, or the Gradio interface.

## Concept

Retentio is an AI-assisted autobiographical memory reconstruction system. It helps people reconnect with forgotten moments by combining fragmented life traces: photos, text fragments, voice notes, places, dates, and contextual search.

## Visual Direction

- Cinematic, emotional, and minimal
- Warm film light against near-black surfaces
- Memory fragments arranged like evidence in a quiet archive
- Soft timelines, glowing traces, and human-centered storytelling
- Modern enough for a hackathon pitch, intimate enough for the product idea

## Included Visuals

- `assets/retentio-hero-poster.svg`: Main cinematic hero poster
- `assets/memory-constellation.svg`: Abstract memory reconstruction map
- `assets/timeline-reconstruction.svg`: Visual timeline for demo or slides
- `assets/ui-preview.svg`: Stylized product interface preview
- `visual-showcase.html`: A standalone visual landing page for previewing the concept
- `visuals.css`: Styling for the showcase page

## How To Use

Open `visual-showcase.html` in a browser to preview the AI hack visuals.

For the actual MVP app, use the project inside `Gaïa/`:

```bash
cd ../Gaïa
pip install -r requirements.txt
python app.py
```

## Pitch Line

Retentio turns scattered life traces into reconstructed emotional timelines, helping people rediscover moments they thought they had lost.
