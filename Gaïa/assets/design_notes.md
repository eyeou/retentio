# Retentio Visual Direction

Retentio should feel emotional, minimal, cinematic, and modern.

## Mood

- Low-light gallery atmosphere
- Warm film tones against a near-black interface
- Quiet typography, no decorative clutter
- Memory output presented like a scene treatment rather than a database record

## Interface Principles

- The first screen is the working reconstruction surface.
- Inputs should feel like evidence trays: fragments, photos, voice, known context.
- Output should feel spacious and readable, with clear sections for emotional core, timeline, context, sensory anchors, and questions.
- Avoid dashboards, heavy chrome, and gamified scoring.

## Future Assets

- Optional background stills from user uploads
- Soft waveform preview for voice notes
- Timeline cards with photo thumbnails
- Exportable memory poster or PDF
